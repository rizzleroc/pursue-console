# One command. Pulls only what helpers need (~10MB instead of 1GB):
curl -fsSL https://rizzleroc.github.io/pursue-console/install-helper.sh | bash

# Then start helping:
cd pursue-helper
npm start                                # launches Chrome + daemon
npm run volunteer -- --my-handle=YOU     # picks 20 pages, OCRs them, opens a PR

The helper script runs OCR + vision locally, commits the results to a fork, and opens a pull request with your handle as the contributor. Reviewers verify on the REVIEW surface. Anonymous OK — set --my-handle=anon.
